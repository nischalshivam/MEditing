# Scene Brain agent rules

Before editing, read `SCENE_BRAIN_MASTER_HANDOFF.md`, `SCENE_BRAIN_CURRENT_STATE.md`, and `SCENE_BRAIN_REGRESSION_CONSTITUTION.md`.

- Film/TV source media is read-only. Never push media, credentials, runtime databases, caches, character images, voiceovers, or machine profiles.
- Local source times and physical evidence are authority. Never accept guessed/model timestamps.
- Weak evidence becomes review/manual; never manufacture confidence.
- Never silently invalidate frozen Walter or Skyler project state or historical receipts.
- Preserve non-ripple editing and all presentation constraints.
- Run the complete regression suite and affected real-browser gates before integration.
- Update canonical docs whenever architecture or employee workflow changes.
- For completed tasks, follow `REPO_SYNC_POLICY.md`: commit and push tested code/docs to `nischalshivam/MEditing`.
- Final replies must report branch, commit SHA, tests, push status, and known defects.
